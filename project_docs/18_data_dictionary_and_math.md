# معجم البيانات والتفاعلات الرياضية (Data Dictionary & Math) 🧮

هذا الملف يوثق جميع الأعمدة المعقدة في قاعدة البيانات والمعادلات الرياضية التي يبنى عليها النظام (التي تعطي قيمة استثمارية وأكاديمية للمشروع).

## 1. جدول الأحياء (Neighborhoods)

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `boundaries_geojson` | Text | يحتوي على إحداثيات (GeoJSON) لتمثيل الحي كمضلع هندسي. |
| `land_price_per_sqm` | Float | متوسط سعر المتر المربع للأساس التجاري. يجلب من **إيجار**. |
| `sun_angle_summer` | Float | **زاوية الشمس الصيفية:** تحسب بناءً على موقع الرياض `(Lat: 24.7)` وانحراف الشمس في يونيو `(Declination: +23.5)`. المعادلة الأساسية للظهيرة: `90 - Lat + Declination = 88.8°`. |
| `sun_angle_winter` | Float | **زاوية الشمس الشتوية:** تحسب في ديسمبر `(Declination: -23.5)`. المعادلة للظهيرة: `90 - Lat + Declination = 41.8°`. هذه الأرقام تساعد المصممين المعماريين. |
| `infrastructure_score` | Float | **درجة البنية التحتية (0-100%):** رقم مركب (Composite Index). |

### كيف يتم حساب `infrastructure_score`؟
يُحسب بناءً على معادلة مرجحة (Weighted Equation) من خدمات الحي:
- **الحدائق (Parks):** وزن 30%. إذا كانت مساحة الحدائق تغطي أكثر من 5% من الحي، يأخذ العلامة الكاملة.
- **المستشفيات (Hospitals):** وزن 25%. يحسب بناءً على عدد الأسرة لكل 1000 نسمة.
- **الطرق والمخارج (Exits):** وزن 25%. يعتمد على القرب من الدائري الشمالي/الشرقي.
- **الخدمات (مدارس/بقالات):** وزن 20%.

## 2. جدول العقارات (Properties)

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `price` | Float | السعر الإجمالي للعقار (بالريال). |
| `area_sqm` | Float | مساحة العقار المربع. |
| `price_per_sqm` | Float | **سعر المتر المربع:** يُحسب تلقائياً (Computed) `price / area_sqm`. مهم جداً للمقارنة الاستثمارية (ROI). |

## 3. مؤشر العائد على الاستثمار (ROI Index)
في لوحات التحكم (Dashboards)، نقوم بحساب العائد المتوقع للاستثمار العقاري (Gross Rental Yield):
**المعادلة:**
`ROI (%) = (Average Annual Rent for 3BR / Total Property Price) * 100`

إذا كان العائد السنوي > 7%، يُصنف العقار كـ **"استثمار عالي الجدوى" (High Yield)** في واجهة الذكاء الاصطناعي.
