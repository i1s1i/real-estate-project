# منصة العقار الذكية - الرياض 🏢🇸🇦

هذا المشروع هو منصة عقارية متقدمة (نموذج أكاديمي/MVP) تعتمد على سحب البيانات (Web Scraping)، وتكاملات API، والخرائط التفاعلية لتحليل السوق العقاري في مدينة الرياض.

## 🌟 الميزات الرئيسية
- **خريطة تفاعلية (Interactive Map):** تدعم التلوين الحراري للأحياء بناءً على جودة البنية التحتية.
- **جلب البيانات (Scraping):** سكريبتات Python تعمل بالخلفية لجلب أحدث العقارات من منصات العقار.
- **ربط البيانات الحكومية:** التكامل مع "إيجار" و "وافي" لمعرفة متوسط أسعار المتر وموثوقية المطورين العقاريين.
- **الذكاء الاصطناعي (RAG):** (قيد التطوير) مسار لمساعدة المستخدمين في اتخاذ القرار باستخدام Llama-3 و ChromaDB.

---

## 🛠️ المتطلبات الأساسية (Prerequisites)
تأكد من وجود البرامج التالية على جهازك:
- Python 3.10 أو أحدث.
- Pip (مدير حزم بايثون).
- Git.

---

## 🚀 دليل التشغيل المحلي (Local Setup)

### 1. استنساخ المشروع (Clone the Repository)
```bash
git clone https://github.com/your-username/real-estate-riyadh.git
cd real-estate-riyadh
```

### 2. إنشاء بيئة افتراضية (Virtual Environment)
من الأفضل دائماً عزل بيئة العمل:
```bash
python -m venv venv

# تفعيل البيئة (Windows):
venv\Scripts\activate

# تفعيل البيئة (Mac/Linux):
source venv/bin/activate
```

### 3. تثبيت المكتبات (Install Dependencies)
```bash
pip install -r requirements.txt
```

### 4. تهيئة قاعدة البيانات (Initialize Database)
المشروع يستخدم `SQLite` محلياً. لإنشاء الجداول بناءً على النماذج (`models`):
```bash
python run.py --init-db
```
*(ملاحظة: تأكد من تشغيل سكريبت `generate_real_boundaries.py` لملء حدود الأحياء الجغرافية).*

### 5. تشغيل السيرفر (Run the Server)
```bash
# ضبط التشفير لتجنب مشاكل اللغة العربية في Windows
$env:PYTHONIOENCODING='utf-8'

# تشغيل خادم Flask
python run.py
```
سيعمل المشروع محلياً على الرابط: `http://127.0.0.1:5000`

## 📂 هيكلة المشروع (Project Structure)
- `app/`: الكود المصدري الأساسي (النماذج، المسارات، واجهات الـ API).
- `static/`: ملفات CSS، JavaScript، وملفات البيانات الجغرافية `major_parks.json`.
- `templates/`: قوالب HTML (Jinja2).
- `project_docs/`: مجلد يحتوي على **20 ملفاً توثيقياً وهندسياً** يشرح بنية المشروع من الألف إلى الياء.
