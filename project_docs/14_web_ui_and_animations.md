# واجهة المستخدم والتأثيرات البصرية (Web UI & Animations) 🎨

هذا الملف يشرح بالتفصيل كيفية برمجة وتنفيذ التأثيرات البصرية (UI Skills)، الرسوم البيانية، والخرائط التفاعلية في المشروع ليتمكن أي مطور من إعادة بنائها بدقة.

## 1. محرك التأثيرات البصرية (Interactions Engine)
جميع التأثيرات البصرية يتم التحكم بها عبر ملف مخصص `static/js/interactions.js` يعمل بالتكامل مع فئات CSS (CSS Classes).

### أ. تأثير الظهور التدريجي (Scroll Reveal)
- **آلية العمل:** يعتمد على `IntersectionObserver` في جافاسكريبت. عندما يدخل العنصر في مجال رؤية المستخدم (Viewport)، تتم إزالة فئة الإخفاء.
- **التطبيق:** يتم إضافة خاصية `data-reveal` لأي عنصر (مثل بطاقات العقارات `ptype-card`).
- **التأثير (CSS):** يبدأ العنصر بشفافية `opacity: 0` وموضع لأسفل `translateY(30px)`، وينتهي بـ `opacity: 1` و `translateY(0)` بانسيابية.

### ب. تأثير النبض المائي للأزرار (Ripple Effect)
- **آلية العمل:** عند النقر على أي زر يحمل فئة `.btn-interactive`، يقوم الجافاسكريبت بحساب إحداثيات النقر (X, Y) ورسم دائرة بيضاء شفافة بداخل الزر.
- **التأثير (CSS):** الدائرة تتسع (`scale(4)`) وتتلاشى (`opacity: 0`) في غضون `600ms`.

### ج. تأثير التحميل الوهمي (Skeleton Loaders)
- **الهدف:** منع الشاشة الفارغة أثناء جلب بيانات العقارات من الـ API (لتحسين تجربة المستخدم).
- **التطبيق:** حاوية تحمل `data-skeleton="3"`.
- **التأثير (CSS):** يتم رسم مربعات رمادية مع حركة لمعان (Shimmer) تمر عبرها باستمرار باستخدام `@keyframes`.

### د. تأثير الرفع اللمسي (Card Lift & Tilt)
- **التطبيق:** فئة `.card-lift` لبطاقات العقارات.
- **التأثير (CSS):** عند مرور الفأرة (Hover)، يرتفع العنصر للأعلى `translateY(-5px)` ويزداد ظل المربع `box-shadow` ليعطي إحساساً بالعمق (3D Depth).

## 2. الرسوم البيانية (Charts & Graphics) 📈
- **المكتبة المستخدمة:** `Chart.js` (نسخة مجانية ومفتوحة المصدر).
- **الرسوم المطلوبة:** 
  1. **مقارنة الأسعار (Line Chart):** يعرض تطور أسعار المتر في الأحياء عبر الزمن. خطوط الرسم تكون منحنية بنعومة (`tension: 0.4`) مع تعبئة شفافة متدرجة أسفل الخط (Gradient Fill).
  2. **تحليل استخدام الأراضي (Doughnut Chart):** يوضح نسبة الأراضي البيضاء مقابل المبنية في لوحة إحصائيات الحي.
- **التخصيص (Theming):** جميع الرسوم تتصل بمتغيرات الـ CSS لتغيير ألوانها تلقائياً مع الوضع الداكن/الفاتح.

## 3. الخريطة التفاعلية والرسومات الجغرافية (Map Graphics) 🗺️
- **المكتبة المستخدمة:** `Leaflet.js`.
- **الطبقات البصرية:**
  - **مضلعات الأحياء (Heatmap Polygons):** ترسم باستخدام إحداثيات `GeoJSON`. لون المضلع يتغير من الأحمر إلى الأخضر بناءً على "درجة جودة البنية التحتية" للحي.
  - **مضلعات الحدائق والمماشي:** (مثل ممشى الغدير وحديقة الملك سلمان) ترسم كمضلعات خضراء/زرقاء واضحة (`L.polygon`) للتمييز بين المساحات الكبيرة والنقاط الصغيرة.
  - **عناقيد العقارات (Marker Clusters):** إذا كان هناك 50 عقاراً في حي واحد، تتجمع برقم "50" دائري لتجنب تشوه الخريطة بصرياً، وتتفكك عند التقريب (Zoom).

## 4. نظام الألوان المتغير (CSS Variables & Theming)
- يعتمد التصميم على متغيرات `:root` في ملف `style.css` لضمان السهولة المطلقة في تغيير "ثيم" الموقع بضغطة زر.
- **ألوان الهوية:** تم الاعتماد على تدرجات اللون الذهبي الداكن (`#c9a84c`) ليعكس الفخامة والقيمة العالية للسوق العقاري، مع خلفية زرقاء داكنة جداً (`#0f172a`) تناسب الشاشات الحديثة وتحمي العين في بيئة لوحات البيانات (Dashboards).
